# wego-voice

**唱的当下，就听见自己唱准了。**

Windows 桌面工具。麦克风进来的声音经过音高检测与修正后**立刻**送回耳返 ——
不是唱完再修，是唱的过程中就听到。声线也能当场换。

全程在本机跑，不联网、无账号、声音不出本机。

**[下载](https://github.com/NUDC/wego-voice/releases/latest)** ·
**[官网](https://nudc.github.io/wego-voice/)** — 免安装单文件，双击即用。

---

## 功能

### 实时音高校准

端到端实测 **29.92 ms**。超过 50 ms 会触发延迟听觉反馈效应，人会不自觉地
结巴跑调 —— 那时产品比不开更糟，所以这个数字是前提，不是性能指标。

- 按**调式**量化，不是简单吸附到最近半音
- **颤音会保留**，不会把人唱成 MIDI
- 跑调太离谱时不硬拉，避免刺耳失真
- 修正速度连续可调：从「修得不露痕迹」到「彻底电音」

### 实时声线塑形

打包成具名**角色**，选中即生效；引擎运行时拖滑杆，声音当场改变。

| 维度 | 作用 | 代价 |
|---|---|---|
| **共振峰平移** | 声道长短 → 更细 / 更粗 | 不动音高，**不增加延迟** |
| **频谱倾斜** | 整体明暗 → 更亮 / 更厚 | **不增加延迟** |
| **整体移调** | 音高整体搬移 | 超过 ±5 半音有明显金属感 |

内置 7 个角色（原声 / 少年 / 御姐 / 少女 / 童声 / 大叔 / 电音），
可改、可复制、可新建，存在 `%APPDATA%\com.wego.voice\characters.json`。

> 做得到「像另一个人」，**做不到「像某个指定的人」**。
> 不提供任何声线来源，参考素材由使用者自带；
> 取得被模拟者同意是使用者的责任。

### 从参考音频生成角色

拖一段 WAV 进来，跟你自己的干声比对，自动算出该拧多少共振峰与倾斜。

音高差会测出来但**刻意不采用** —— 参考音源比你高，不代表你该升调去唱，
那就不是这首歌了。「像另一个人」主要由共振峰承担。

### 干声录制

落盘的是**原始干声**，不是耳返里那个修正过的声音。修正音有损且不可逆，
只存它等于放弃了换角色重来、离线重新校准、送进声线转换的机会。

存在「音乐 / wego-voice /」，32-bit float WAV。丢帧数会显示出来 ——
悄悄丢帧比录不上更糟。

### 噪声门

在没有人声的帧更新噪声本底，**有人声时冻结**。它解决的不是"听得到底噪"，
而是两个真症状：风扇、电流声有周期成分，会被当成人声去修；
噪声抬高非周期度，会让修音时断时续。

门关着时不跑音高检测 —— 安静时平均回调耗时从 70 µs 降到 **9 µs**。

### 诊断页

单机软件没有遥测，用户机器上出了问题我们看不见 —— 这一页是唯一的可观测性
来源，也是用户判断"自己这块声卡行不行"的地方。

延迟构成 · 实时健康度（xrun / 溢出 / 整机停顿）· 时钟漂移 ppm ·
输入噪声本底 · 往返延迟实测 · 引擎参数。

### 系统托盘

低延迟模式会**独占声卡**，运行期间系统其他声音会静音。托盘图标的颜色就是
这件事唯一持续可见的信号：灰 = 已停止，蓝 = 运行中，琥珀 = 有爆音。

关闭窗口收进托盘，**退出只能从托盘菜单**。

## 硬件要求

**需要**

- **有线耳机**，或外置声卡 / USB 麦克风
- Windows 10 / 11（x64）
- Microsoft Edge WebView2 运行时（Win11 与较新的 Win10 自带）
- 录音时能让本程序独占声卡

**做不到**

- **蓝牙耳机** —— 编解码本身就有 100~250 ms 延迟，是无线协议的物理限制，
  任何软件都绕不过
- macOS / Linux —— 低延迟路线是 Windows 特有的（WASAPI 独占）
- 手机

> ⚠️ **务必戴耳机。** 外放会让麦克风拾到自己的输出，形成啸叫回路。

---

## 还没做

- 基于神经网络的**离线声线转换**（「像某个指定的人」那一档）
- 伴奏导入、调性自动检测
- 离线重新校准（没有 30 ms 约束，质量会高于实时版）
- 分轨导出、批量处理、预设存取、键盘快捷键
- 输出水印与 AI 生成标识

## 构建

需要 Rust（stable，MSRV 1.80）+ Node 20+。

```bash
cd app
npm install
npm run tauri build -- --no-bundle     # 产物：target/release/wego-voice-app.exe
cargo test --release --workspace
```

> 🔴 **打包必须走 `npm run tauri build`，不能直接 `cargo build`。**
> 后者出来的 exe 前端是死的：开窗即空白、零 IPC，看起来像应用崩了。

三种入口，同一个可执行文件：

```bash
wego-voice-app.exe               # GUI
wego-voice-app.exe --autostart   # 开窗即启动引擎
wego-voice-app.exe --bench       # headless 压测，不创建 WebView
wego-voice-app.exe --selftest    # 自检
```

音频测量工具 `wego-bench`：

```bash
wego-bench devices                          # 列设备
wego-bench soak -d 600 --mute               # 10 分钟连测，查时钟漂移
wego-bench dsp -d 30 --formant-shift 4      # 离线量 DSP 成本，不碰声卡
wego-bench timbre --reference 她.wav --source 我.wav
wego-bench --help
```

> ⚠️ 量 DSP 成本必须用 `dsp` 子命令。`soak` 喂的是真实麦克风 ——
> 没人唱歌时判为清音，PSOLA 直接透传，测出来的跟 DSP 真实成本无关。

官网：

```bash
cd site
npm run dev      # http://localhost:5174
npm run build    # 预渲染成零 JavaScript 的静态页
```
